# PATTERN 1: The search loop

**Say this sentence to yourself and you can rewrite the function:**
> *Push start. Pop the smallest. Is it the goal? Done. Otherwise push its neighbours.*

Only three things ever change between programs:

| Program | `neighbors()` (where can I go?) | `priority` (what do I pop first?) | `is_goal` |
|---|---|---|---|
| Best First | the `graph` dict | `h[n]` | `n == 'G'` |
| A\* | the `graph` dict | `g + h[n]` | `n == 'G'` |
| Water Jug | the 6 pour/fill/empty moves | `g` (fewest steps first, i.e. BFS) | `TARGET in s` |
| N-Queens | add a safe queen in the next row | `-g` (deepest first, i.e. DFS) | `len(s) == N` |

(`g` = cost so far, `h` = guess of the cost still to go.)

## 1 and 7. Best First Search and A\* (this is the CORE, learn this one)

**Aim:** Find a path from S to G using a heuristic.

**Algorithm (write this in your answer):**
1. Put the start node in a priority queue.
2. Pop the node with the smallest priority. If it is the goal, stop.
3. Otherwise push all its neighbours and repeat.
4. Best First uses priority = h(n). A\* uses priority = g(n) + h(n).

```python
import heapq

graph = {                          # node -> {neighbour: cost}
    'S': {'A': 1, 'B': 4},
    'A': {'C': 2},
    'B': {'G': 12},
    'C': {'G': 3},
    'G': {}
}
h = {'S': 6, 'A': 5, 'B': 2, 'C': 3, 'G': 0}     # heuristic = guess of distance to G


def neighbors(n):                  # where can I go from n?  -> (node, cost) pairs
    return graph[n].items()


def search(start, is_goal, priority):
    pq = [(priority(start, 0), 0, start, [start])]       # (priority, g, node, path)
    seen = set()
    while pq:
        _, g, node, path = heapq.heappop(pq)             # take smallest priority
        if is_goal(node):
            return path, g
        if node in seen:
            continue
        seen.add(node)
        for nxt, cost in neighbors(node):
            heapq.heappush(pq, (priority(nxt, g + cost), g + cost, nxt, path + [nxt]))
    return None


goal = lambda n: n == 'G'

print("Best First:", search('S', goal, lambda n, g: h[n]))        # priority = h
print("A*        :", search('S', goal, lambda n, g: g + h[n]))    # priority = g + h
```

**Output:**
```
Best First: (['S', 'B', 'G'], 16)
A*        : (['S', 'A', 'C', 'G'], 6)
```
Best First is greedy: it grabbed the node that *looked* closest (B) and paid 16. A\* found the cheapest path (cost 6).

## 5. Water Jug Problem

**Aim:** Measure exactly `TARGET` litres using two jugs.

**Algorithm:**
1. A state is `(x, y)` = litres in jug 1 and jug 2. Start at `(0, 0)`.
2. From any state apply 6 moves: fill 1, fill 2, empty 1, empty 2, pour 1 to 2, pour 2 to 1.
3. Search level by level (priority = steps taken) until a jug holds `TARGET`.

The `search()` function is **identical** to the core. Only `neighbors` and the last lines are new.

```python
import heapq

CAP = (4, 3)                       # jug sizes
TARGET = 2                         # litres wanted in any jug


def neighbors(s):                  # all states reachable in one move
    x, y = s
    a, b = CAP
    t = min(x, b - y)              # amount poured x -> y
    u = min(y, a - x)              # amount poured y -> x
    moves = [(a, y), (x, b),       # fill jug 1, fill jug 2
             (0, y), (x, 0),       # empty jug 1, empty jug 2
             (x - t, y + t),       # pour 1 -> 2
             (x + u, y - u)]       # pour 2 -> 1
    return [(m, 1) for m in moves if m != s]


def search(start, is_goal, priority):
    pq = [(priority(start, 0), 0, start, [start])]
    seen = set()
    while pq:
        _, g, node, path = heapq.heappop(pq)
        if is_goal(node):
            return path, g
        if node in seen:
            continue
        seen.add(node)
        for nxt, cost in neighbors(node):
            heapq.heappush(pq, (priority(nxt, g + cost), g + cost, nxt, path + [nxt]))
    return None


result = search((0, 0), lambda s: TARGET in s, lambda s, g: g)     # priority = g  -> shortest steps (BFS)
if result:
    for step in result[0]:
        print(step)
    print("Steps:", result[1])
else:
    print("No solution")
```

**Output:**
```
(0, 0)
(0, 3)
(3, 0)
(3, 3)
(4, 2)
Steps: 4
```
Change `CAP` and `TARGET` for other jug sizes (e.g. `CAP = (5, 3)`, `TARGET = 4`).

## 10. N-Queens

**Aim:** Place N queens on an N x N board so that none attack each other.

**Algorithm:**
1. A state is a tuple of columns, one queen per row, filled row by row.
2. From a state, add a queen to the next row in every column that is not in the same column or on the same diagonal as an earlier queen.
3. Go deepest first (priority = `-g`). When the state has N queens, stop.

Same `search()` again. Change `N` for other board sizes.

```python
import heapq

N = 4


def neighbors(state):              # state = column of the queen in each row so far
    r = len(state)                 # next row to fill
    return [(state + (c,), 1) for c in range(N)
            if all(c != c2 and abs(c - c2) != r - r2 for r2, c2 in enumerate(state))]


def search(start, is_goal, priority):
    pq = [(priority(start, 0), 0, start, [start])]
    seen = set()
    while pq:
        _, g, node, path = heapq.heappop(pq)
        if is_goal(node):
            return path, g
        if node in seen:
            continue
        seen.add(node)
        for nxt, cost in neighbors(node):
            heapq.heappush(pq, (priority(nxt, g + cost), g + cost, nxt, path + [nxt]))
    return None


path, _ = search((), lambda s: len(s) == N, lambda s, g: -g)     # priority = -g  -> deepest first (DFS)
board = path[-1]
print("Columns:", board)
for c in board:
    print(' '.join('Q' if i == c else '.' for i in range(N)))
```

**Output:**
```
Columns: (1, 3, 0, 2)
. Q . .
. . . Q
Q . . .
. . Q .
```

## 11. Hill Climbing

**Aim:** Climb to a better state by always moving to the best neighbour, and stop when no neighbour is better.

**Algorithm:**
1. Start at some state.
2. Look at all neighbours and pick the one with the best (lowest) `h`.
3. If it is not better than the current state, stop (peak or local optimum). Otherwise move there and repeat.

It reuses the same `graph`, `h` and `neighbors` as the core, but there is **no queue**: it forgets everything except where it is now. That is the difference from Best First.

```python
graph = {
    'S': {'A': 1, 'B': 4},
    'A': {'C': 2},
    'B': {'G': 12},
    'C': {'G': 3},
    'G': {}
}
h = {'S': 6, 'A': 5, 'B': 2, 'C': 3, 'G': 0}


def neighbors(n):
    return graph[n].items()


def hill_climb(start, h):
    cur, path = start, [start]
    while True:
        best = min((n for n, _ in neighbors(cur)), key=h, default=None)   # best neighbour only
        if best is None or h(best) >= h(cur):      # nobody is better -> stop (peak / local optimum)
            return path
        cur = best
        path.append(cur)


print("Graph  :", hill_climb('S', lambda n: h[n]))

# Same function on numbers: minimise (x-3)^2, neighbours are x-1 and x+1
def neighbors(x):
    return [(x - 1, 1), (x + 1, 1)]

print("Numbers:", hill_climb(0, lambda x: (x - 3) ** 2))
```

**Output:**
```
Graph  : ['S', 'B', 'G']
Numbers: [0, 1, 2, 3]
```

# PATTERN 2: Tree recursion

**Say this sentence:**
> *If it's a leaf, return its value. Otherwise ask every child, then combine the answers.*

Only the "combine" step changes:

| Program | Leaf returns | How children are combined |
|---|---|---|
| MinMax | the score | MAX node: `max(children)`, MIN node: `min(children)` |
| Alpha-Beta | the score | same, plus `alpha`/`beta` and a `break` to skip children |
| AO\* | `h[leaf]` | OR: `min` over the options, AND: `sum` of the children in one option |

## 2. MinMax

**Aim:** Find the best move value for MAX in a game tree.

**Algorithm:**
1. If the node is a leaf, return its score.
2. Recursively evaluate every child, flipping MAX/MIN at each level.
3. MAX takes the largest child value, MIN takes the smallest.

```python
tree = [[[3, 5], [6, 9]], [[1, 2], [0, -1]]]     # nested lists, numbers at the bottom are scores


def minimax(node, is_max):
    if isinstance(node, int):                     # leaf -> return its score
        return node
    scores = [minimax(child, not is_max) for child in node]
    return max(scores) if is_max else min(scores)


print("Optimal value:", minimax(tree, True))      # root is MAX
```

**Output:**
```
Optimal value: 5
```

## 9. Alpha-Beta Pruning

**Aim:** Get the same answer as MinMax while skipping branches that cannot change the result.

**Algorithm:**
1. Same recursion as MinMax. `alpha` = best value MAX can already guarantee, `beta` = best value MIN can already guarantee.
2. After each child, update `alpha` (at MAX) or `beta` (at MIN).
3. If `alpha >= beta`, stop looking at the remaining children (prune).

Same tree as MinMax. The `visited` list proves the pruning.

```python
tree = [[[3, 5], [6, 9]], [[1, 2], [0, -1]]]     # same tree as minimax
INF = float('inf')
visited = []                                      # leaves we actually looked at


def alphabeta(node, is_max, alpha=-INF, beta=INF):
    if isinstance(node, int):
        visited.append(node)
        return node
    best = -INF if is_max else INF
    for child in node:
        score = alphabeta(child, not is_max, alpha, beta)
        if is_max:
            best = max(best, score)
            alpha = max(alpha, best)
        else:
            best = min(best, score)
            beta = min(beta, best)
        if alpha >= beta:                         # prune: remaining children can't matter
            break
    return best


print("Optimal value:", alphabeta(tree, True))
print("Leaves visited:", visited)                 # 9, 0, -1 were pruned
```

**Output:**
```
Optimal value: 5
Leaves visited: [3, 5, 6, 1, 2]
```

## 8. AO\* Algorithm

**Aim:** Find the cheapest solution in an AND-OR graph.

**Algorithm:**
1. Each node has OPTIONS (OR). Each option is a group of children that must **all** be solved (AND).
2. A leaf costs its heuristic `h`.
3. Cost of an option = sum of (1 + cost of each child). Cost of a node = cheapest option. Remember which option won.
4. Print the chosen options starting from the root. That is the solution graph.

This is the simple version (graph has no cycles, every node is fully expanded), which is what lab programs normally show.

```python
graph = {                          # node -> list of OPTIONS (OR); each option = list of children (AND)
    'A': [['B', 'C'], ['D']],      # A = (B AND C)  OR  D
    'B': [['E'], ['F']],           # B = E  OR  F
    'C': [['G', 'H']],             # C = G AND H
    'D': [['I']],
}
h = {'E': 4, 'F': 2, 'G': 1, 'H': 2, 'I': 9}     # estimate for leaf nodes
best = {}                                         # chosen option for each node


def ao(node):
    if node not in graph:                         # leaf
        return h[node]
    best_cost = float('inf')
    for option in graph[node]:
        cost = sum(1 + ao(child) for child in option)   # AND -> add all children (edge cost 1)
        if cost < best_cost:                            # OR  -> keep the cheapest option
            best_cost, best[node] = cost, option
    return best_cost


def show(node):                                   # print only the chosen solution graph
    if node in best:
        print(node, "->", " AND ".join(best[node]))
        for child in best[node]:
            show(child)


print("Cost of A:", ao('A'))
show('A')
```

**Output:**
```
Cost of A: 10
A -> B AND C
B -> F
C -> G AND H
```

# PATTERN 3: Short standalones

## 3. Cryptarithmetic Problem

**Aim:** Replace each letter with a different digit so that SEND + MORE = MONEY.

**Algorithm:**
1. Collect the unique letters.
2. Try every way of giving them different digits (`permutations`).
3. Skip any assignment where a first letter is 0.
4. Stop at the first one where the sum is correct.

```python
from itertools import permutations

w1, w2, res = "SEND", "MORE", "MONEY"
letters = sorted(set(w1 + w2 + res))              # unique letters


def num(word, d):                                 # word -> number using the digit mapping d
    return int(''.join(str(d[c]) for c in word))


for p in permutations(range(10), len(letters)):   # try every digit assignment
    d = dict(zip(letters, p))
    if 0 in (d[w1[0]], d[w2[0]], d[res[0]]):      # first letters can't be 0
        continue
    if num(w1, d) + num(w2, d) == num(res, d):
        print(d)
        print(num(w1, d), "+", num(w2, d), "=", num(res, d))
        break
```

**Output:**
```
{'D': 7, 'E': 5, 'M': 1, 'N': 6, 'O': 0, 'R': 8, 'S': 9, 'Y': 2}
9567 + 1085 = 10652
```
SEND+MORE=MONEY has 8 letters, so it takes about 2 to 3 seconds. Smaller puzzles such as `TWO + TWO = FOUR` or `TO + GO = OUT` are instant. Only edit the line `w1, w2, res = ...`.

## 4. Chatbot

**Aim:** A rule-based chatbot that replies from keywords.

**Algorithm:**
1. Keep a dictionary of keyword and reply.
2. Read the user's message and split it into lowercase words.
3. If a keyword is in the words, print its reply. If none match, print a default reply.
4. Stop when the user types `bye`.

```python
import re

rules = {                          # keyword -> reply
    'hello': "Hi! How can I help you?",
    'hi': "Hello there!",
    'name': "I am PyBot, a simple chatbot.",
    'help': "I can chat about greetings, my name and the weather.",
    'weather': "I can't check live weather, but I hope it's sunny!",
}

print("Bot: Hello! Type 'bye' to exit.")
while True:
    words = re.findall(r'\w+', input("You: ").lower())    # split into lowercase words
    if 'bye' in words:
        print("Bot: Goodbye!")
        break
    for key, reply in rules.items():
        if key in words:
            print("Bot:", reply)
            break
    else:                                                  # no keyword matched
        print("Bot: Sorry, I didn't understand that.")
```

**Sample run:**
```
Bot: Hello! Type 'bye' to exit.
You: hello
Bot: Hi! How can I help you?
You: what is your name
Bot: I am PyBot, a simple chatbot.
You: tell me a joke
Bot: Sorry, I didn't understand that.
You: bye
Bot: Goodbye!
```

**Bonus (very short, uses NLTK, needs no downloads):**

## 6. NLTK

**Aim:** Basic text processing with NLTK.

**Algorithm:** Split into sentences, then words (tokenize), remove stopwords, stem, lemmatize, tag parts of speech, count word frequency.

```python
import nltk
from nltk.tokenize import sent_tokenize, word_tokenize
from nltk.corpus import stopwords
from nltk.stem import PorterStemmer, WordNetLemmatizer

for pkg in ['punkt', 'punkt_tab', 'stopwords', 'wordnet', 'omw-1.4',
            'averaged_perceptron_tagger', 'averaged_perceptron_tagger_eng']:
    nltk.download(pkg, quiet=True)                # one-time download (needs internet)

text = "The striped bats are hanging on their feet and flying faster. NLTK makes language processing easy!"

print("Sentences   :", sent_tokenize(text))
tokens = word_tokenize(text)
print("Tokens      :", tokens)

stop = set(stopwords.words('english'))
clean = [w for w in tokens if w.isalpha() and w.lower() not in stop]
print("No stopwords:", clean)

print("Stems       :", [PorterStemmer().stem(w) for w in clean])
print("Lemmas      :", [WordNetLemmatizer().lemmatize(w) for w in clean])
print("POS tags    :", nltk.pos_tag(tokens))
print("Top words   :", nltk.FreqDist(w.lower() for w in clean).most_common(3))
```

**What it prints:** seven lines (Sentences, Tokens, No stopwords, Stems, Lemmas, POS tags, Top words).

If the lab PC has **no internet**, the `nltk.download(...)` line cannot fetch data. Ask whether NLTK data is already installed. Without data, these still work: `PorterStemmer().stem(...)`, `nltk.tokenize.wordpunct_tokenize(text)` (instead of `word_tokenize`) and the `nltk.chat` bonus above.

# Quick checklist before you run

- Search programs: did you write `import heapq`?
- Hill climbing: `min(..., default=None)`: the `default=None` stops a crash on a dead end.
- Minimax: `not is_max` flips the level. Forgetting it makes every level MAX.
- Alpha-Beta: the prune test is `alpha >= beta`, placed **after** updating alpha/beta.
- AO\*: `sum(...)` for AND, `min` (the `if cost < best_cost`) for OR.
